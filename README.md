Project Overview
This repository contains the solutions for Lab #4b, covering structured JSON dataset creation, asynchronous data retrieval via the native `fetch()` API, and DOM/event manipulation using jQuery 4.0.0.

How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code and launch `books.html` using **Live Server** (do not open directly via `file://` due to browser CORS restrictions on `fetch()`).
3. Open `jquery-dom.html` in a modern desktop browser or via Live Server.

Files Included
- `books.json` — Valid JSON dataset containing two book objects.
- `books.html` — Fetches and displays book details from `books.json` with error handling.
- `jquery-dom.html` — Implements DOM text updates, class styling, and click events using jQuery 4.0.0.
